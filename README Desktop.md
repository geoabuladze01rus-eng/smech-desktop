# Смеч Desktop 0.6 — macOS и Windows

Это настольная оболочка существующего «Смеч» 0.5 с локальным FastAPI, PDF/Excel-движком и окном pywebview. Новые функции коммерческого расчёта **не заменяют сметную документацию ФСНБ/ГЭСН**.

## Два типа поставки

1. **Готовый исполняемый файл**, создаваемый GitHub Actions на соответствующей операционной системе: `Smech.exe` в папке `Smech` (Windows x64); `Smech.app` и `.dmg` (macOS Apple Silicon и Intel). Пользователю не нужно устанавливать Python. Эти файлы появляются **только после успешного выполнения сборки** на Windows/macOS. Локальная Linux-среда не создаёт Windows/macOS бинарники.
2. **Исходный комплект для пробного запуска**, поставляется здесь: `start-windows.bat` / `start-macos.command`. Требуются Python 3.12 и доступ к PyPI при первом запуске для установки зависимостей. После установки приложение запускается в отдельном окне; для основных функций интернет не нужен.

## Как сделать готовые приложения автоматически

1. Создать GitHub-репозиторий (публичный или частный) для проекта «Смеч».
2. Загрузить в его корень **содержимое** этого архива, включая скрытую папку `.github/workflows` (не вложенную папку с названием проекта).
3. В репозитории открыть Actions → `Смеч — сборки Windows и macOS` → Run workflow.
4. После завершения трёх заданий скачать Artifacts: Windows x64, macOS Apple Silicon и macOS Intel. Для macOS каждый артефакт содержит `.zip` приложения и `.dmg`.

Каждая сборка сначала устанавливает зависимости, запускает автоматические тесты, затем PyInstaller и smoke-test собранного исполняемого файла. Без успешного smoke-test архив не публикуется. **Отдельные релизы пока не подписаны сертификатами разработчика**; при первом запуске Windows SmartScreen и macOS Gatekeeper могут показать предупреждение. Для широкого распространения нужны подпись, Apple Developer ID и нотариализация (macOS), сертификат подписи кода (Windows).

В публичном репозитории стандартные GitHub-hosted Actions обычно доступны без оплаты; ограничения сервиса и правила использования необходимо соблюдать. В этом комплекте сборка не запускалась, денег не списывалось. На бесплатном тарифе и квоты для macOS/Windows могут отличаться.

## Запуск исходников на Windows

Развернуть ZIP в отдельную папку. Установить Python 3.12 x64 с https://www.python.org/downloads/windows/ с компонентом Python Launcher. Дважды нажать `start-windows.bat`. При первом запуске установятся Python-зависимости, затем откроется окно «Смеч». Для встроенного окна необходим **Microsoft Edge WebView2 Runtime** (обычно присутствует в Windows 11; если его нет, установить у Microsoft). Папку `.venv-desktop` можно удалить при необходимости переустановки зависимостей. Базовые расчёты и электронные PDF работают локально.

## Запуск исходников на macOS

Развернуть ZIP. Установить Python 3.12 с https://www.python.org/downloads/macos/. Открыть Терминал, перейти в каталог программы и выполнить `./start-macos.command`, либо открыть `.command` в Finder, если система разрешает. При первом запуске устанавливаются зависимости, затем откроется отдельное окно. Для Mac с Apple Silicon и Intel нужен соответствующий пакет Python. Команда `python3` должна указывать на Python 3.11+.

## Где хранятся данные

* Windows: `%LOCALAPPDATA%\Smech\`.
* macOS: `~/Library/Application Support/Smech/`.
* `webview/` — отдельный профиль локального хранилища приложения (папку не удалять).
* `workspace.sqlite3` — SQL-база дополнительного режима «Рабочее пространство» после его активации через настройки.
* `backups/workspace-ГГГГ-ММ-ДД.sqlite3` — резервные копии SQL-базы при запуске (по одной в сутки, до 14). **Данные обычного локального режима в webview в эти SQLite-копии не входят.** Для них используется кнопка «Резервная копия JSON» в интерфейсе.
* `desktop.log` — журнал ошибок запуска; на него не отправляется телеметрия.

Данные в обычном режиме сохраняются внутри WebKit/WebView2 по стабильному локальному адресу `http://127.0.0.1:18765`. При каждом запуске приложение занимает этот порт эксклюзивно. Если порт уже занят, появится сообщение; не запускайте параллельно два экземпляра. Сервер слушает **только 127.0.0.1**. Облачных передач данных нет.

**Перенос со старой браузерной версии 0.5:** сначала скачать JSON резервную копию со старой версии, затем в новой открыть настройки и восстановить данные. Профиль браузера не импортируется автоматически. Нельзя просто переименовать каталог WebView — localStorage привязан к точному origin.

## PDF и OCR

- Электронные PDF читаются встроенными pdfplumber и pypdfium2.
- **Распознавание сканированных PDF (OCR) требует отдельно установленного Tesseract и русских языковых данных `rus`**. Python-библиотеки OCR (pytesseract, OpenCV, Pillow) входят в комплект; внешняя программа Tesseract и языковые файлы не включены. На Windows обеспечить путь к `tesseract.exe` через `PATH`, на macOS поставить `tesseract` и `rus` языковой пакет (например через Homebrew). Проверка: `tesseract --list-langs` должен показывать `rus`.
- Настольная версия не превращает геометрические чертежи в объёмы работ; OCR ошибается, каждую строку проверять по оригиналу.

## Проверка разработчиком

```text
python -m pip install -r requirements-desktop.txt -r requirements-dev.txt
python -m pytest -q
python scripts/build_native.py
```

Последняя команда вызывается **на целевой ОС**. Сборку для другой ОС PyInstaller не выполняет. Готовый исполняемый файл поддерживает проверку `--self-test` без открытия окна. На Windows сборка в `dist/Smech/Smech.exe`; на macOS в `dist/Smech.app`.

## Ограничения перед коммерческим внедрением

Нет подписи и нотариализации установщиков, нет встроенного OCR, нет автосинхронизации между macOS и Windows. SQL-рабочее пространство внутри каждого настольного приложения является локальным: **перенос базы между компьютерами вручную, совместной работы через сеть нет**. Отдельное многопользовательское серверное решение потребует развёртывания и аудита. Нет официальных российских сметных нормативов, испытаний на реальных ВОР и кроссплатформенных системных испытаний готовых приложений. Первичные данные и ставки должны проверяться сметчиком.
