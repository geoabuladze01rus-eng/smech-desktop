# Изменения «Смеч» 0.5

- Дополнен PDF-парсер: координаты исходных строк, просмотр страниц через PDFium, сверка SHA-256.
- Новый модуль `specifications.py`, страница импорта и сравнения спецификаций.
- Добавлены страницы Excel-экспорта для спецификаций и сверки.
- В серверном пространстве добавлена двухэтапная фиксация решений по неизменяемым снимкам.
- Миграция БД Alembic 0002, 12 новых проверок, 45 успешных тестов суммарно.
- Уточнены ограничения: нет автоматического определения объёмов по геометрии чертежей, нормативной базы РФ и юридически значимой электронной подписи.
