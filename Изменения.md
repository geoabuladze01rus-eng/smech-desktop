# Изменения «Смеч» 0.3 (6 ноября 2026 года)

## Новое

1. Режим самостоятельной работы остался прежним: локальное хранение в браузере, расчёт на FastAPI, XLSX/CSV/JSON.
2. Дополнительный серверный режим с учётными записями, Argon2-паролями, сеансами через HttpOnly cookie, CSRF и ограничением доступа к объектам. У каждого сотрудника личный справочник материалов; коммерческие цены уже привязанных материалов заморожены в объекте.
3. Права на объект: owner (владелец), editor (редактор), viewer (просмотр). Назначение и отзыв прав доступны владельцу; создание сотрудников — системному администратору.
4. Предупреждение и блокировка сохранения при конфликте редакций. Сервер использует оптимистичную блокировку на каждой записи и предотвращает частичные изменения в пакете операций.
5. Журнал пользователя, даты, версии и изменившихся полей. Добавлено сравнение двух соседних редакций, включая изменение цены и источника материала.
6. Долговечные архивные снимки расчётов со значением SHA-256. Через обычный API снимки не изменяются. Удаление объекта мягкое, с возможностью восстановления через корзину владельца.
7. Ручной импорт проектов из локального режима без перезаписи существующих идентификаторов; цены старых ссылок на справочник фиксируются при импорте.
8. Подготовлена схема SQLAlchemy для SQLite/PostgreSQL и начальная миграция Alembic `0001`.
9. Добавлены настройки серверного режима в интерфейс. Приложение не требует платного стороннего API и не передаёт проекты на внешние серверы без явной настройки.

## Исправления

- Отсутствующее поле необходимости материалов теперь блокирует готовность расчёта, а не считается решением инженера.
- Отклоняются числа с более чем 12 знаками после запятой и при использовании десятичной запятой.
- Проверяется отсутствие NaN/Infinity при сохранении объектов и справочника.
- Импорт старых ведомостей больше не оставляет цены материалов зависимыми от чужого каталога, если исходные записи доступны.
- Ошибка доступа к localStorage больше не показывается как ошибка серверного хранилища при работе в облачном режиме.

## Проверено

27 автотестов (ядро, Excel, API, права доступа, конфликты, снимки, удаление и восстановление, перенос, фиксация цен). Проверка JavaScript через `node --check`. Начальная миграция Alembic испытана на чистой SQLite. В тестовом Chromium через API-посредник успешно открывались интерфейс, регистрация первого администратора и создание объекта; ошибок JavaScript не было. Сам PostgreSQL в живом окружении не запускался.

## Ограничения

Сервис не публиковался в интернете. Требуется развёртывание PostgreSQL с TLS-прокси, настройка резервного копирования и мониторинга. Предусмотрены ручные действия при конфликтах; автоматического слияния нет. Не реализованы PDF/OCR, BIM, нормативные базы РФ, подтверждение коммерческих расчётов и восстановление пароля сотрудника. Нормативность ставок, налогов, цен и объёмов по загруженным документам программа не гарантирует.
