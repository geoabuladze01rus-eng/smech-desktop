# Безопасность «Смеч»

Репозиторий публичный. **Не загружайте** сюда исходные сметы заказчиков, коммерческие предложения, персональные данные, пароли, приватные ключи, файлы `.env`, рабочие базы SQLite и резервные копии.

Настольное приложение запускает HTTP API только на `127.0.0.1`, но до промышленного внедрения необходим независимый аудит безопасности, включая проверки доступа из браузера, CSRF и локального рабочего пространства. Доступ по сети в текущем виде не поддерживается.

Для сообщения об уязвимости используйте приватный канал владельца репозитория, а не публичный issue, если публикация даёт возможность эксплуатации.
