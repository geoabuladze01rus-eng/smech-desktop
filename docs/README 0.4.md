# «Смеч» 0.4 — коммерческий расчёт СМР с импортом PDF-ведомостей

Версия 0.4 от 7 ноября 2026 года. Сохраняет функциональность версии 0.3 и добавляет локальное чтение PDF-ведомостей с обязательной ручной проверкой. Это коммерческий калькулятор подрядчика, а не официальная сметная программа по ФСНБ/ГЭСН.

## Что работает

- Объекты, ВОР, Excel/CSV/TSV, привязка материалов, нормативов расхода по собственным данным, сдельные ставки, себестоимость, начисления, накладные, коммерческая наценка, режим НДС, экспорт.
- Дополнительное многопользовательское пространство SQLAlchemy (SQLite для испытаний, PostgreSQL — подготовленный вариант), роли, журнал изменений, архив, контроль конфликтов редакций.
- Загрузка PDF с текстовым слоем, поиск табличных областей по линиям и без них. Для сканов с видимой сеткой таблицы — опциональное локальное OCR Tesseract, только после включения пользователем.
- Объединение одинаково размеченных таблиц с разных страниц, сохранение исходных строк и идентификатора оригинала SHA-256. В поле «Источник» добавляется название PDF, номер страницы, таблицы, строки, хеш документа.
- До вставки в ВОР пользователь назначает столбцы, видит строки, редактирует название/единицу/объём, отмечает проверенные позиции. Автоматического импорта всех строк при открытии нет. Для OCR отключено массовое выделение по кнопке: строки выбираются вручную по одной.
- Система не рассчитывает объёмы по текстовому описанию, не предлагает материалы по одному названию работы и не подставляет «средние» цены или зарплаты. После переноса поля материала/ставки остаются пустыми.

## Локальный запуск

Python 3.11+. В распакованной папке выполните:

```bash
python -m pip install -r requirements-pdf.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. В меню **Ведомость работ → Импорт PDF / Excel** загрузите документ. Для цифровых PDF этого достаточно.

### Если ведомость является сканом

Установите локальный исполняемый **Tesseract OCR** вместе с языковыми пакетами `rus` и `eng` и зависимости:

```bash
python -m pip install -r requirements-ocr.txt
```

В окне импорта включите флажок «Разрешить локальное OCR». В Windows следует убедиться, что `tesseract.exe` доступен в PATH. В Debian/Ubuntu языковые пакеты обычно называются `tesseract-ocr-rus` и `tesseract-ocr-eng`. OCR работает на машине, где запущен FastAPI, а не в телефоне пользователя. Скан без чёткой сетки таблицы может остаться нераспознанным. Даже успешно прочитанные числа и единицы необходимо сопоставить с оригиналом.

**Пределы:** PDF до 15 МБ, до 40 страниц; OCR не более 10 страниц за загрузку. Для других форматов остаются ограничения версии 0.3. Зашифрованные PDF с паролем не читаются. В документе может быть несколько групп таблиц с разными заголовками: в текущей версии их загружают в ВОР по очереди.

## Данные и безопасность

PDF обрабатывается сервером, который вы запустили. Содержание не отправляется сторонним OCR/ИИ-провайдерам. Программа не сохраняет оригинальный загруженный PDF в базу; сохраняется только текст выбранных строк и источник с SHA-256. **Сохраняйте исходные файлы отдельно** для последующей сверки. Тестовый сервер запускайте только на `127.0.0.1`; публикация в интернет без TLS, настройки доступа и дополнительной проверки безопасности не поддерживается.

Многопользовательский режим версии 0.3 не включён по умолчанию. Для него действуют прежние инструкции о `SMECH_ENABLE_WORKSPACE=1`, SQLite/PostgreSQL, ролях и секретах; см. `docs/README 0.3.md`. Это не проверенный публичный SaaS-сервис.

## Проверка

```bash
python -m pip install -r requirements-dev.txt
python -m pip install -r requirements-ocr.txt
python -m pytest -q
node --check static/app.js
node --check static/workspace.js
```

**Результат текущей ревизии: 33 успешных автоматических теста**. Проверены наследованные расчёты и права доступа, электронный PDF из двух страниц, повтор заголовков, источник, SHA-256, локальное OCR по скану, запрет файла с паролем, лимит страниц и API импорта. В изолированном Chromium с тестовыми ответами API пройдены создание объекта, выбор полей PDF, отказ от импорта без выделенных строк, выбор пяти строк и их перенос с источником, без ошибок JavaScript. Полноценный браузерный тест с прямым подключением к реальному FastAPI был ограничен политикой среды; API отдельно проверен через `TestClient`.

Учебные файлы: `Пример ВОР для PDF 0.4.pdf` и `Пример скана ВОР для OCR 0.4.pdf`. Объёмы в них вымышленные и не подходят для реальной сметы. Повторно сгенерировать образцы можно командой `python demo_pdf.py` в среде разработки с ReportLab, PDFium и кириллическим TTF-шрифтом.

## Лицензии и коммерческое применение

PDF-модуль версии 0.4 использует **pdfplumber (MIT)** и **pypdfium2 (Apache-2.0/BSD-3-Clause с дополнительными лицензиями PDFium)**. PyMuPDF из экспериментального варианта исключён из исполняемого кода и тестов из-за режима AGPL/коммерческого лицензирования. Перед распространением сборки необходимо проверить лицензии всех транзитивных зависимостей и выполнить требования об уведомлениях и включении лицензий. Это не юридическое заключение о соблюдении лицензий.

Источники: https://github.com/jsvine/pdfplumber/blob/stable/LICENSE.txt ; https://pypi.org/project/pypdfium2/ ; https://pymupdf.io/licensing .

## Ограничения перед коммерческим внедрением

Не испытана работа на реальных многостраничных ведомостях заказчиков, сложных сканах, таблицах без границ и чертежах. Не подключены ФСНБ-2022, ГЭСН, ФГИС ЦС, сметные нормативные расчёты и проверка по исходным чертежам. Не проводились эксплуатационные нагрузочные испытания PostgreSQL, внешний тест на проникновение и развёртывание на общедоступном сервере. Для выдачи цены заказчику требуется проверка инженером-сметчиком исходных объёмов, затрат и условий договора.

## Структура обновлений

- `pdfio.py` — PDF/OCR, идентификация страниц и хеш оригинала.
- `app.py` — расширенный маршрут `/api/import?ocr=true`.
- `static/app.js` и `static/styles.css` — проверка и редактирование PDF-строк.
- `requirements-pdf.txt`, `requirements-ocr.txt` — отдельные PDF/OCR-зависимости.
- `tests/test_pdfio.py`, `demo_pdf.py` — регрессии и тестовые PDF.
- `docs/README 0.3.md` — описание исходной версии 0.3 и серверного режима.
- `Аудит 0.4.md` — журнал ревизии, устранённые риски и план 0.5.
