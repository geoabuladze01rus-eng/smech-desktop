# Изменения 0.4

Версия основана на исходниках 0.3, структура API расчётов и многопользовательского пространства сохранена.

Добавлено: цифровые PDF; выбор OCR для сканов; табличная разметка и ручной просмотр; проверка обязательных полей до импорта; фиксация PDF-источника, страницы, номера строки и SHA-256; тестовые документы и регрессионные тесты. Из приложения исключена зависимость от PyMuPDF, использованы pdfplumber и pypdfium2.

Не добавлено: автоматическая расценка, подбор материалов по ИИ, составление нормативной сметы, чтение объёмов с чертежей, хранение самих PDF в базе.
