# Смеч Desktop 0.6: изменения

- Новое нативное окно для macOS (WKWebView) и Windows (Edge WebView2), общее расчётное ядро FastAPI.
- Локальный HTTP-сервер привязан к 127.0.0.1 и фиксированному порту 18765; запуск второго экземпляра на том же порту отклоняется.
- Постоянный профиль данных пользователя вне папки программы, раздельное хранение localStorage и SQLite.
- Ежедневное резервирование SQLite при следующем запуске приложения (до 14 копий); JSON-экспорт по-прежнему нужен для локальных объектов.
- Скрипты быстрого запуска из исходников для обеих систем (первичная установка Python-пакетов через PyPI).
- PyInstaller-сборка и workflow GitHub Actions: Windows x64, macOS Apple Silicon, macOS Intel.
- Режим `--self-test` для безоконной проверки упакованной сборки на целевой системе.
- Новые тесты хранения, резервирования, локального HTTP и блокировки порта.

Ограничения: настоящие .exe/.app/.dmg пока не собраны на Windows/macOS; цифровая подпись не настроена, OCR требует отдельно установленного Tesseract, совместная работа по сети не включена.
