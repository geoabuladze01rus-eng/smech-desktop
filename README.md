# Смеч Desktop 0.6

**«Смеч»** — настольный прототип для работы с ведомостями объёмов работ, материалами, оплатой СМР и коммерческими расчётами. Работает локально на Windows и macOS. Интерфейс на русском языке.

## Сборки Windows и macOS

Откройте [GitHub Actions](https://github.com/geoabuladze01rus-eng/smech-desktop/actions/workflows/build-desktop.yml). Workflow `Смеч — сборки Windows и macOS` запускает тесты и создаёт три комплекта:

- **Windows x64:** папка `Smech` с `Smech.exe` в ZIP.
- **macOS Apple Silicon:** `Smech.app` в ZIP и DMG.
- **macOS Intel:** `Smech.app` в ZIP и DMG.

Доступные артефакты успешной сборки находятся в нижней части страницы запуска Actions. Это **экспериментальные неподписанные сборки**: антивирус и Gatekeeper могут потребовать ручного подтверждения. Установщик `.msi`/`.exe` пока не создан; Windows поставляется как переносимая папка. Для сканов PDF нужен отдельно установленный Tesseract OCR с русским языковым пакетом.

Для запуска напрямую из исходного кода используйте `start-windows.bat` или `start-macos.command`. Инструкции в [README Desktop.md](README%20Desktop.md).

## Архитектура

- Python + FastAPI — локальный API, импорт Excel/PDF, расчёты.
- `pywebview` — собственное окно программы на Windows/macOS.
- SQLite — локальное рабочее пространство по выбору пользователя; основной режим хранит проекты в профиле webview.
- GitHub Actions + PyInstaller — отдельные нативные сборки под целевые платформы.

**Условия:** программа — испытательный прототип, не предназначена для выдачи проверенных смет без участия специалиста. Нормативные базы ФСНБ/ГЭСН/ФГИС ЦС не подключены. Вычисления и импорт необходимо проверять на реальных объектах. История исходного кода публична, но отдельная лицензия на проект пока не выбрана. Не публикуйте реальные данные заказчиков и ключи доступа.
